# RB-M365-003 Outlook profile rebuild

## Purpose / When to use

Use when classic Outlook (Microsoft 365 Apps) on a Windows PC is misbehaving for one user and the usual quick fixes did not help: repeated password prompts, stuck "Trying to connect" or "Disconnected", search not returning results, missing folders, shared mailboxes that will not load or will not go away, crashes on launch, or sync stuck on "Updating this folder". A profile rebuild fixes most single-user classic Outlook problems.

This runbook is for **classic Outlook**. New Outlook for Windows does not use MAPI profiles or OST files; for new Outlook, see the note at the end.

## Prerequisites / access needed

- Beacon RMM remote session to the user's PC
- The user's password (the user types it; we never ask for it)
- 20-30 minutes; the new OST will download mail in the background

## Before you rebuild (quick checks, 10 minutes max)

1. Confirm it is just this user. If others at the client have Outlook problems at the same time, check https://status.cloud.microsoft and the M365 admin center **Health > Service health** before touching anything. Multi-user problems go to RB-GEN-001 for re-triage (likely P2).
2. Confirm the user can sign in to Outlook on the web (https://outlook.office.com). If OWA fails too, it is an account problem (RB-ACC-001), not a profile problem.
3. Start Outlook in safe mode: **Win+R > `outlook.exe /safe`**. If it works in safe mode, disable add-ins (File > Options > Add-ins > COM Add-ins > Go) and test. Add-ins (PDF tools, CRM plugins, dental/legal practice software plugins) are a common crash cause.
4. Check for Office updates: File > Office Account > Update Options > Update Now.
5. Repeated password prompts: clear cached credentials in **Credential Manager > Windows Credentials**, remove entries starting with `MicrosoftOffice16_Data` and `msteams` / `OneAuth` related entries for the user, then sign out of Office apps (File > Office Account > Sign out) and restart.

If those do not fix it, rebuild.

## Steps

1. **Note the current setup** before you remove anything: additional mailboxes the user opens, PST files attached (File > Account Settings > Data Files), signatures, and any rules that run client-side only.
2. **Back up signatures:** copy `%APPDATA%\Microsoft\Signatures` to the desktop.
3. **PST files:** note their paths. Do not delete them. Larkspur standard is no PSTs on network shares; if you find one on a share, mention it in the ticket for follow-up.
4. **Close Outlook** and confirm `OUTLOOK.EXE` is not running in Task Manager.
5. **Create a new profile:** Control Panel (switch to Large icons) > **Mail (Microsoft Outlook)** > **Show Profiles** > **Add**. Name it `Outlook-YYYYMMDD`.
6. Enter the user's name and email address; the user types their password and completes MFA (Authenticator push with number matching).
7. On the Mail dialog, select **Always use this profile** and pick the new profile. Leave the old profile in place for now as a fallback.
8. **Launch Outlook.** Let it start downloading. Confirm the "Mail to keep offline" setting is appropriate (File > Account Settings > Account Settings > select account > Change). Standard is **1 year**; heavy users with large mailboxes can go lower to keep the OST manageable.
9. **Re-add** PST files (File > Open & Export > Open Outlook Data File) if the user still needs them, and restore signatures by copying the folder back.
10. Shared mailboxes with Full Access and automapping reappear on their own. Mailboxes added manually must be re-added (File > Account Settings > Change > More Settings > Advanced > Add).
11. **Verify:** send and receive a test message, check calendar, search for a recent email (search index rebuilds over the next hour or so), and open any shared mailboxes.
12. **Clean up** after the user confirms things are good (same day or next day): delete the old profile from the Mail control panel. Old OST files in `%LOCALAPPDATA%\Microsoft\Outlook` can be deleted once the old profile is removed.

## Search not working after rebuild

- Give it time; the Windows Search index rebuilds after a new OST downloads.
- Check indexing status: in Outlook, click the search box > Search Tools > **Indexing Status**.
- If it is still broken the next day: Control Panel > Indexing Options > Advanced > **Rebuild**. Rebuilding the index affects the whole PC and can take hours; tell the user.

## New Outlook for Windows

- New Outlook has no profile or OST. To "reset" it: Settings > Apps > Installed apps > Outlook (new) > Advanced options > **Reset**. The user signs in again.
- If the user prefers classic Outlook and the client allows it, toggle off **New Outlook** in the upper right of new Outlook.

## Priority guidance

- Single user, OWA works as a workaround: **P3**.
- VIP unable to use mail at all on their PC: **P2** (but give them OWA right away).
- Multiple users with Outlook problems at once: not this runbook; re-triage as **P2** or **P1**.

## Escalate if

- A rebuild does not fix it and OWA works: Tier 2 (if you are Tier 1), then Renee Castillo for mailbox-side issues (corrupt items, mailbox move, quota).
- Autodiscover errors pointing to an old on-prem Exchange server (hybrid clients or old migrations): Renee Castillo.
- You need to remove or repair a PST over 20 GB: Tier 2.

## Ticket notes

- Symptom and quick checks done (safe mode, add-ins, credential clear)
- New profile name, cache setting, PSTs re-attached, signatures restored
- Verification steps and user confirmation
- Date the old profile was deleted
