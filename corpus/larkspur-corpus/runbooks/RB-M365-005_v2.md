# RB-M365-005 OneDrive / SharePoint sync errors

## Purpose / When to use

Use when a user sees a red X or a "sync pending" icon on OneDrive, "Sync is paused", files not showing up for coworkers, "Upload blocked", duplicate files with the PC name appended, or a SharePoint library that will not sync. Covers the OneDrive sync app on Windows 11, including Known Folder Move (Desktop, Documents, Pictures redirected to OneDrive), which is our standard for all managed PCs.

## Prerequisites / access needed

- Beacon RMM remote session
- SharePoint admin center / M365 admin center via GDAP for storage and site permissions
- The user signed in on the PC

## Steps

### 1. Look at what OneDrive says

1. Click the OneDrive cloud icon in the system tray. Read the error. Common ones:
   - **"Sync is paused"**: someone paused it, or Battery Saver / metered connection paused it. Click **Resume**.
   - **"You're not signed in"** or a sign-in prompt: password changed or token expired. Sign in.
   - **"Can't sync" with a file count**: click "View sync problems" for the list.
   - **"Your OneDrive is full"** or **"SharePoint site storage is full"**: see step 5.
2. Check https://status.cloud.microsoft for a SharePoint/OneDrive incident if several users report it.

### 2. Common file-level problems

3. **Invalid names and paths:** OneDrive cannot sync names containing `" * : < > ? / \ |`, names with leading/trailing spaces, or reserved names (CON, PRN, AUX, NUL, COM1, LPT1, `.lock`, `desktop.ini`, `_vti_`). The full decoded path must stay under **400 characters**. Deep folder trees copied from old file servers often hit this; shorten folder names.
4. **Open or locked files:** a file open in another app (QuickBooks company files, Access databases, PST files, CAD files) will not sync or will corrupt. **PST and QuickBooks/Access database files do not belong in OneDrive or SharePoint.** Move them out (to the local disk or the client's file server if they have one) and tell the user why.
5. **Storage full:**
   - User OneDrive: default 1 TB per user. M365 admin center > Users > select user > OneDrive tab shows usage.
   - SharePoint site: SharePoint admin center > **Sites > Active sites** shows storage used vs. limit. Increasing a site limit comes out of the tenant pool; ask Renee Castillo before changing.
6. **File conflicts:** duplicates named `file-PCNAME.docx` mean two people edited offline. Have the user compare and keep the right one. Co-authoring in Office apps avoids this; encourage opening files from Office rather than double-clicking locally while offline.

### 3. Reset the sync client

7. If errors persist with no specific file named, reset OneDrive:
   - Press **Win+R** and run `%localappdata%\Microsoft\OneDrive\onedrive.exe /reset`
   - If that path does not exist, try `C:\Program Files\Microsoft OneDrive\onedrive.exe /reset`.
   - Wait 2 minutes; if OneDrive does not restart, run `onedrive.exe` from the same path.
8. Reset does not delete files. It re-syncs everything, which can take hours for large libraries. Tell the user, and do it at lunch or end of day if possible.
9. Make sure the OneDrive app is current (it updates itself; Beacon RMM reports the version).

### 4. SharePoint library sync

10. Users should sync SharePoint libraries with **Add shortcut to My files** (preferred) or the **Sync** button, not both for the same library. Both at once causes duplicate paths and errors. Remove one.
11. If a library sync shows "You don't have permission": check the user's access to the site (Site settings > Site permissions, or the Team membership in Teams). Granting access needs approval from the site owner or an authorized contact.
12. Libraries over about 300,000 items sync poorly. If the client is syncing a massive library, escalate rather than fight it.

### 5. Known Folder Move issues

13. Desktop/Documents not backing up: OneDrive > Settings > **Sync and backup > Manage back up**. Confirm folders show "Files backed up". KFM is enforced by Intune policy at most clients; if it shows an error, check for a folder that was redirected to a network share in the past (Folder Redirection GPO at hybrid clients) and escalate if so.
14. Files "missing" from the Desktop after KFM: they are usually in `C:\Users\<user>\OneDrive - <Company>\Desktop`. Check there, and check the OneDrive **Recycle bin** (online) and the site Recycle bin. Deleted items are kept 93 days total across first- and second-stage recycle bins. For older deletions, see RB-BAK-001.

## Priority guidance

- Single user sync errors, files accessible online: **P3**.
- User cannot access files needed today and the web is not an option: **P3** (P2 for VIP fully blocked).
- Multiple users unable to reach a key SharePoint library: **P2**.
- Files appear to be deleted or overwritten across a library: **P2** and go to RB-BAK-001; if files are being renamed with strange extensions, treat as P1 and call Tom Kessler immediately.

## Escalate if

- Mass file deletion or rename activity: Tom Kessler (immediately) and Renee Castillo.
- Site storage limit changes, site permissions redesign, or library restructuring: Renee Castillo (may become project work for Rachel Kim).
- KFM conflicts with legacy Folder Redirection: Renee Castillo.
- Restore needed beyond the recycle bin: RB-BAK-001.
